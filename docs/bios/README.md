# BIOS files (local only)

Put the BIOS files you own here (`neogeo.zip`, `pgm.zip`, `scph5501.bin`…). **Nothing in this
folder is committed**: BIOS files are copyrighted and Vuretro does not provide them. Add them to
the app from **Cores & BIOS** (drop them on the page), or copy them to the app's `system` folder.
